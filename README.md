## Get started
Clone this repository and run the script
```bash
git clone https://github.com/salanpro/hyprland
cd hyprland/
./setup.sh
./post-install.sh
```
>It should be executable, if not then `chmod +x setup.sh`
>
After the script ends, reboot your system to apply all the changes

To change the icons press `MOD + R` to open vicinae launcher and browse GTK Settings, or in terminal type `GTK Settings` 
>I think it's no longer needed bc of gtk the folders added in .config, not tested yet
>

## Features
* Alacritty _( Terminal )_
* Vicinae _( App Launcher )_
* Waybar _( Bar )_
* Swaync _( Panel and notifications )_
* Hyprlock _( Screen lock )_
* Hypridle _( IDLE management )_
* Hyprshot _( Screenshots )_
* Satty _( Editing screenshots )_
